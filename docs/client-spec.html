1. Overview

The client is a Python 3.11+ asynchronous daemon that probes one or more upstream AI-agent rate-limit endpoints, normalises each into an agent-agnostic AgentSnapshot, and pushes each snapshot to a BurnScope ESP32 display over HTTP. The ESP32 is discovered on the LAN via mDNS (overridable). Each agent declares its own probe_interval class attribute; a --probe-interval CLI flag overrides every agent globally. Pushes to POST /summary are edge-triggered: identical-content probes don't re-POST. Between content changes the daemon hits GET /health as the heartbeat / liveness probe so a dead device is noticed without forcing a firmware repaint.

Every concrete agent has the same shape: a *Credential frozen dataclass (telling us where credentials live and what fields they have) and an *Agent subclass (telling us how to probe and what to extract). Adding a new agent is a pure subclass-and-register operation; nothing else in the client knows about specific providers.

schema.py

client/src/burnscope_client/schema.py

Purpose

Defines the agent-agnostic wire-format dataclasses. The single source of truth on the wire is wire-format.md; this module is the Python mirror of it.

Public surface

NameKindDescription

credentials.py

client/src/burnscope_client/credentials.py

Purpose

Defines the Credential abstract base class and the shared reading capabilities that every *Credential subclass composes inside its own load().

Public surface

NameKindDescription
CredentialsErrorexception Raised when credentials cannot be located or parsed.
CredentialABC Base class for an agent's credential blob. Subclasses are frozen dataclasses with a load() classmethod.
Credential.load(**kwargs)abstract classmethod Subclasses implement with their own signature (paths / service names).
Credential._read_keychain(service)static Runs security find-generic-password -s <service>; returns stdout. Raises on non-zero rc or empty output.
Credential._read_file(path)static Reads path as text; raises if not found.
Credential._parse_json(blob, source)static Parses blob as JSON; on JSONDecodeError raises CredentialsError mentioning source.

Behaviour

No I/O happens at module import. Each reader is a static method on the base class — subclasses call them via cls._read_… for readability and discoverability. The class hierarchy is purely a mixin-style code-sharing device; Credential has no instance state of its own.

Error handling

RaisesWhen
CredentialsError _read_keychain: security command returned non-zero or empty stdout.
CredentialsError _read_file: file not found.
CredentialsError _parse_json: blob is not valid JSON.

Tests

  • Tested transitively through ClaudeCredential.load() and CodexCredential.load() in test_credentials.py — see the claude.py and codex.py sections below.

agent.py

client/src/burnscope_client/agent.py

Purpose

Defines the Agent abstract base class — the contract every upstream provider must satisfy — and ProbeError, the shared error type for probe failures.

Public surface

NameKindDescription
ProbeErrorexception Raised by Agent.probe() implementations on transport failure, non-2xx response, or missing/malformed rate-limit headers.
AgentABC Base class. Subclasses define name, __init__(credential), probe(), load_credential().
Agent.nameClassVar[str] Wire-format identifier ("claude", "codex", …). Also the --agent CLI value.
Agent.probe(client)abstract async Issues one upstream probe; returns AgentSnapshot; raises ProbeError on any failure.
Agent.load_credential()abstract classmethod Reads this agent's credential from local storage. Raises CredentialsError.
Agent.try_create()classmethod Returns cls(cls.load_credential()) if available, else None. Used by CLI auto-detect.

Behaviour

try_create() is the only concrete method on the base. It catches CredentialsError exclusively — any other exception bubbles. Subclasses do not need to override it because the credential type encapsulates all per-agent fields.

Error handling

RaisesWhen
ProbeError Subclasses raise during probe() for HTTP errors, 4xx/5xx responses, or unparseable headers.
CredentialsError Bubbles up from load_credential() when called directly. Suppressed inside try_create().

agents/claude.py

client/src/burnscope_client/agents/claude.py

Purpose

Probes Anthropic's rate-limit headers for Claude Code's subscription windows.

Public surface

NameKindDescription
ClaudeCredentialfrozen dataclass(Credential) Field: access_token: str. Class method load(keychain_service, credentials_path).
ClaudeAgentAgent subclass name = "claude". Class attributes KEYCHAIN_SERVICE, CREDENTIALS_PATH.
API_URL, PROBE_MODEL, USER_AGENTmodule const Probe target and request shape constants.

Behaviour

Credential location. On macOS, reads security find-generic-password -s "Claude Code-credentials". Elsewhere, reads ~/.claude/.credentials.json. Both paths are class attributes on ClaudeAgent so the agent class is the single source of truth.

Credential parsing. Either claudeAiOauth.accessToken or top-level accessToken is accepted (the Claude Code CLI has produced both shapes historically).

Probe. POST https://api.anthropic.com/v1/messages with max_tokens=1, model claude-haiku-4-5-20251001, message "hi". Required headers: Authorization: Bearer <token>, anthropic-version: 2023-06-01, anthropic-beta: oauth-2025-04-20, User-Agent: claude-code/2.1.5. Timeout: 10s.

Header parsing. Reads anthropic-ratelimit-unified-{5h,7d}-{utilization,reset}. utilization is already a 0.0–1.0 float (no scaling). reset is ISO-8601 with a trailing Z; bare unix-seconds digits are also accepted. Missing pairs are skipped rather than failing. A response with neither pair raises ProbeError.

Inputs / outputs

Input ClaudeCredential (constructor), then an httpx.AsyncClient per probe() call.
Output AgentSnapshot(agent="claude", captured_at=int(time.time()), sessions=[SessionSnapshot("5h", …), SessionSnapshot("7d", …)])

Error handling

RaisesWhen
ProbeErrorAny httpx.HTTPError during the POST.
ProbeErrorResponse status ≥ 400 (message includes the first 200 bytes of the body).
ProbeErrorNeither 5h nor 7d pair present.
ProbeErrorUtilization value isn't parseable as a float, or reset value isn't a valid ISO-8601 / digit string.
CredentialsErrorFrom ClaudeCredential.load(): keychain miss, file not found, malformed JSON, no accessToken.

agents/codex.py

client/src/burnscope_client/agents/codex.py

Purpose

Probes ChatGPT Codex's rate-limit headers. Mirrors docs/probe-codex.sh.

Public surface

NameKindDescription
CodexCredentialfrozen dataclass(Credential) Fields: access_token: str, account_id: str | None = None. Class method load(credentials_path).
CodexAgentAgent subclass name = "codex". Class attribute CREDENTIALS_PATH.
API_URLmodule const https://chatgpt.com/backend-api/codex/responses

Behaviour

Credential location. ~/.codex/auth.json (declared as CodexAgent.CREDENTIALS_PATH). tokens.access_token is required; tokens.account_id is optional.

Probe. Streaming POST https://chatgpt.com/backend-api/codex/responses. The body is an SSE event stream that we deliberately never consume — we open the stream, read response headers, and exit the async with context, which closes it. This keeps the probe cheap and bypasses needing to parse SSE.

Required headers: Authorization: Bearer <token>, Content-Type: application/json, OpenAI-Beta: responses=experimental, and ChatGPT-Account-ID: <account_id> only if account_id is set on the credential. Timeout: 10s.

Header parsing. Reads x-codex-{primary,secondary}-{used-percent,reset-at}. used-percent is an integer 0–100 and is divided by 100.0 to fit the wire format's 0.0–1.0 contract. reset-at is unix-seconds. Missing pairs are skipped; an empty result raises ProbeError.

Inputs / outputs

Input CodexCredential (constructor), then an httpx.AsyncClient per probe() call.
Output AgentSnapshot(agent="codex", captured_at=int(time.time()), sessions=[SessionSnapshot("primary", …), SessionSnapshot("secondary", …)])

Error handling

RaisesWhen
ProbeErrorAny httpx.HTTPError during the streamed POST.
ProbeErrorResponse status ≥ 400 (drained body included up to 200 bytes).
ProbeErrorNeither primary nor secondary pair present.
ProbeErrorMalformed used-percent (not float-parseable) or non-integer reset-at.
CredentialsErrorFrom CodexCredential.load(): file not found, malformed JSON, missing tokens.access_token.

discovery.py

client/src/burnscope_client/discovery.py

Purpose

Locates a BurnScope ESP32 on the LAN via mDNS, or parses a user-supplied override.

Public surface

NameKindDescription
SERVICE_TYPEconst "_burnscope._tcp.local."
discover_esp32(timeout=10.0, *, zc=None)async fn Browses for SERVICE_TYPE; returns "host:port" on first hit, None on timeout. zc is injectable for tests.
parse_host_override(value, default_port=80)fn Normalises a CLI override into "host:port"; adds the default port if missing.

Behaviour

Uses zeroconf.asyncio.AsyncServiceBrowser. On the first Added event we resolve the service info, take the first IPv4 address, and complete an internal Future. Resolution failures (no IPv4, missing port) are quietly ignored — the browser keeps running and we wait for the next event until the timeout fires. The browser and zeroconf instance are cleanly cancelled / closed in the finally block.

Error handling

Returns / raisesWhen
returns None Timeout elapsed with no usable service.
returns "host:port" First service resolved to a valid IPv4 + port.

daemon.py

client/src/burnscope_client/daemon.py

Purpose

Orchestrates probe scheduling, mDNS discovery, and push delivery for one or more agents inside a single asyncio loop.

Public surface

NameKindDescription
DaemonConfigdataclass agents: list[Agent], esp32_host: str | None, probe_interval: float | None (optional global cadence override), tick, discovery_timeout.
DiscoverFntype alias Callable[[], Awaitable[str | None]] — injection point for tests.
run(config, *, stop_event=None, discover_fn=None)async fn Main loop. Returns when stop_event is set.

Behaviour

Cadence. _current_interval returns config.probe_interval when set (global override), otherwise the agent's own probe_interval class attribute. The loop wakes every tick seconds (or earlier if stop_event fires).

Probing. For each agent, if now - last_probe_ts ≥ interval, await agent.probe(http). On success, cache the snapshot. On any exception, log a warning and back off by setting last_probe_ts = now - interval + tick so the next attempt is one tick away — a failing agent doesn't burn the loop. Failures are isolated per agent.

Discovery. If cached_host is None and any agent has a snapshot to push, call discover_fn(). config.esp32_host (when set) is treated as a permanent cache — never invalidated on push or health failure. An mDNS-discovered host is dropped (and rediscovered next tick) when this tick's network attempt failed: either every push attempted this tick failed, or no push was needed and the /health heartbeat failed.

Pushing (edge-triggered). For each agent with a cached snapshot, compare its payload ((agent, sessions) — captured_at is excluded because it changes every probe) to state.last_pushed_snapshot. POST only if they differ. On success, last_pushed_snapshot is updated to the just-pushed value and last_push_failed is cleared. No retries within a cycle — if the comparison still shows a delta next tick, the push runs again. This prevents the firmware from being repainted at the daemon's probe cadence (which would override its on-device agent rotation; see firmware FSD § FR-4.6 and § FR-4.10).

Heartbeat. On any tick where no agent's payload changed (so no /summary went out), the daemon does a single GET /health via _check_health. Failures are logged at WARNING and flip the same "drop the cached host" path as a push failure. The firmware does not act on /health beyond returning JSON, so this request has no visible side-effect on the device.

Validation. An empty agents list raises ValueError. The CLI is responsible for never passing one.

Inputs / outputs

Input DaemonConfig, an optional asyncio.Event for shutdown, an optional discover_fn.
Output Side-effecting HTTP POSTs via pusher.push; log output via logging. Returns None.

Error handling

Raises / handlesWhen
raises ValueError config.agents is empty.
swallows all probe exceptions Logged at WARNING; agent backs off one tick.
swallows all push exceptions Logged at WARNING; mDNS host invalidated when every push attempted this tick failed (no push attempts → not counted).
swallows all health exceptions Logged at WARNING; an mDNS-discovered host is dropped so it is rediscovered next tick.
swallows mDNS discovery exceptions discover_fn failure means cached_host stays None; retried next tick.

cli.py

client/src/burnscope_client/cli.py

Purpose

Command-line entry point. Parses flags, builds the list of agents (either from --agent or by auto-detect), wires signal handlers, and runs the daemon loop.

5. Per-cycle lifecycle

One full iteration of the daemon's outer loop. http is the shared httpx.AsyncClient. 

sequenceDiagram
  participant CLI as cli.py
  participant Daemon as daemon.run()
  participant Agent as Agent.probe()
  participant Upstream as Anthropic / ChatGPT
  participant Discovery as discover_esp32()
  participant Pusher as pusher.push()
  participant ESP32 as ESP32 /summary

  CLI->>Daemon: run(config, stop_event)
  loop while not stop_event.is_set()
    par per agent
      alt now - last_probe_ts ≥ probe_interval
        Daemon->>Agent: await probe(http)
        Agent->>Upstream: POST (single token / streaming)
        Upstream-->>Agent: rate-limit headers
        Agent-->>Daemon: AgentSnapshot
      else not yet due
        Daemon-->>Daemon: skip
      end
    end
    opt no cached_host AND any snapshot
      Daemon->>Discovery: discover_esp32()
      Discovery-->>Daemon: "host:port" or None
    end
    opt cached_host known
      Daemon->>ESP32: GET /health
      ESP32-->>Daemon: 200 JSON (firmware-side sessions) / transport error
      loop per agent with snapshot
        alt payload differs from firmware-side sessions
          Daemon->>Pusher: push(snapshot, host, http)
          Pusher->>ESP32: POST /summary
          ESP32-->>Pusher: 204
        else unchanged
          Daemon-->>Daemon: skip (no POST)
        end
      end
      opt all push attempts failed AND host was mDNS-discovered
        Daemon-->>Daemon: cached_host = None (rediscover next tick)
      end
    end
    Daemon->>Daemon: await stop_event.wait(timeout=tick)
  end
